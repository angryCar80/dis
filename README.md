# Dis (Diractories Interaction Site)

Cli tool fully made in C
which the cli tool is going to make it easy to access config file or projects
Personaly I struggled with that

### Build

```sh
git clone https://github.com/angryCar80/dis.git
cd dis
make
```

The binary will be at `build/main`.
